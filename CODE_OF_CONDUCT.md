# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, insults, and personal or political attacks are not accepted in issues, pull requests, reviews or any other project space.

## Reporting

If someone's behaviour breaks this code, contact the maintainer, [@alihdrndm](https://github.com/alihdrndm), through the contact options on that GitHub profile. Reports are handled privately. The maintainer may remove comments, close issues or block participants who break this code.
